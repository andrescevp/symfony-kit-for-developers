## Why SymfonyKD

SymfonyKD is a pre-release VS Code extension focused on Symfony productivity.
It brings Symfony project exploration, framework intelligence, console command workflows,
and a Symfony-focused chat participant into one developer experience.

Use this documentation to install quickly, learn daily workflows, and review supported capabilities.

## Join the Insiders Program

Get early access to pre-release SymfonyKD builds, test unreleased Symfony DX features in real projects,
and share feedback directly through GitHub.

[Apply for the Insiders Program](https://github.com/andrescevp/symfony-kit-for-developers/issues/new?template=insider_application.yml)
by opening the GitHub issue application form.

## Who this extension is for

- Symfony developers who want faster daily navigation and execution workflows inside VS Code.
- Teams evaluating Symfony-focused tooling before standardizing editor workflows.
- Developers using AI-assisted workflows with Symfony context and command safeguards.
