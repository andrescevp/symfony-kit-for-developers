SymfonyKD works in Symfony project workspaces inside VS Code.

## Minimum prerequisites

- VS Code
- A Symfony project workspace
- PHP and Symfony CLI or console access in your project environment

## Recommended setup

- Keep project dependencies installed and autoload metadata current.
- Ensure command execution environment in VS Code matches your terminal runtime.
- Use version control before running broader refactors from language tooling.

## Pre-release note

SymfonyKD is currently in pre-release.

Expect active iteration, rapid changes, and occasional breaking adjustments while core workflows stabilize.
